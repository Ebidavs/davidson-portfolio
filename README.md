# Davidson Ebute-metta — Personal Portfolio

Responsive React + Vite personal portfolio, with sections for About, Projects, Skills, Journey, and Contact.

## Run locally

1. Install Node.js (18+).
2. Open this folder in VS Code.
3. In the VS Code terminal, run:

```bash
npm install
npm run dev
```

4. Open the local URL printed in the terminal (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

Deploy the project to Vercel by importing the GitHub repository, selecting the Vite framework preset, and using `npm run build` with output folder `dist`.

## Personalisation

- Edit copy, project links, and sections in `src/main.jsx`.
- Edit colors, layout, and responsive design in `src/style.css`.
- The resume download is at `public/documents/Davidson_Ebute-metta_Resume.pdf`.
- No date of birth or private personal-profile document is published.
- The project previews are original CSS illustrations, not actual screenshots. Replace them with project screenshots if desired.

- All showcased project links should be reviewed before publishing.
